# Portafolio de Proyectos de Machine Learning

## Introducción

Este repositorio presenta un portafolio de proyectos enfocados en **Machine Learning, análisis de datos y desarrollo de soluciones interactivas**. A través de diferentes aplicaciones y notebooks se exploran conceptos fundamentales y prácticos relacionados con el aprendizaje automático, desde la preparación y análisis de datos hasta modelos de regresión y clasificación.

El portafolio reúne proyectos desarrollados durante el proceso de formación, cada uno acompañado de una aplicación interactiva, su repositorio en GitHub y, cuando corresponde, su notebook de Google Colab. Esto permite consultar tanto el resultado final como el desarrollo y experimentación detrás de cada proyecto.

## Proyectos

Entre los temas abordados se encuentran:

- Descenso de Gradiente Interactivo
- Detección de anomalías y análisis de complejidad
- Preparación y estructura de datos
- Predicción de calidad del aire
- Regresión lineal y optimización mediante gradiente
- Series de tiempo
- Sistemas IoT para captura y procesamiento de datos
- Regresión logística para predicción de lluvias
- Clasificación mediante KNN

Cada proyecto cuenta con etiquetas temáticas que permiten identificar rápidamente los principales conceptos trabajados, como **Machine Learning, Estadística, Regresión, Clasificación, Series de Tiempo, IoT, NumPy y Análisis de Datos**.

## Tecnologías y herramientas

El portafolio integra herramientas y tecnologías utilizadas para el desarrollo, experimentación y despliegue de los proyectos, entre ellas:

- Python
- Streamlit
- Google Colab
- GitHub
- NumPy
- Machine Learning
- Análisis estadístico
- Visualización y procesamiento de datos

## Estructura del portafolio

Cada proyecto se presenta mediante una tarjeta interactiva que permite acceder directamente a:

1. **Aplicación:** versión interactiva y desplegada del proyecto.
2. **GitHub:** código fuente del proyecto.
3. **Colab:** notebook utilizado para el desarrollo y experimentación.

De esta manera, el portafolio permite explorar los proyectos desde una perspectiva tanto práctica como técnica.
